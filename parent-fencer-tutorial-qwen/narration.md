# Parent and fencer guide — Qwen instructional edition

## Add a fencer and add a tournament

Number one. Add a fencer and add a tournament.

This guide follows seven tasks for a parent and fencer. We use fictional names and demo recordings.

First, enter the fencer's name. Here, we use Alex Rivera.

Tap Continue to save the name. The app uses one fencer profile.

Tap the plus button to add a tournament.

Enter a tournament name. You can also set its date, location, and time zone.

Tap Save to create the tournament.

The tournament is ready. Next, add its schedule or enter bouts yourself.

## Add a schedule from a screenshot

Number two. Add a schedule from a screenshot.

To use a schedule screenshot, tap Import Schedule.

Tap Select schedule screenshots. The app opens the Photos picker.

Select the schedule screenshot. Make sure the names and table are clear.

Tap Add to read the selected screenshot.

Scroll to the proposed bouts. Check opponents and bout numbers. Correct any mistakes before saving.

Tap Confirm Schedule when the details are correct. The app saves the confirmed bouts.

The bout list now shows the imported schedule. The screenshot and proposed text stay on this device.

## Add a bout manually

Number three. Add a bout manually.

You can also add a bout without a screenshot. Open Import Schedule again.

Tap Manual Entry.

Tap Add proposed bout to create an empty row.

Enter the opponent's name. We will use Casey Jordan.

Enter the bout number from the full bout order. Use a positive number that does not conflict with another bout.

Check the new row, then tap Confirm Schedule.

The manual bout now appears beside the imported bouts.

## Import videos into a bout

Number four. Import videos into a bout.

Before importing videos, open the correct bout. Every selected recording will go into this bout.

Tap Import Recordings to open the recording review screen.

Tap Select Recordings to open the Photos picker.

Select the first recording from this bout.

Select any other recordings from the same bout. Several recordings can belong to one bout.

Tap Add to load the selected recordings.

If your device asks, tap Allow Full Access so the app can read the selected recordings.

Check the import results. If one recording fails, you can still confirm the successful recordings.

Confirm the import to attach these recordings to the bout. The original videos stay unchanged in Photos.

The recordings are now linked to this bout. The app orders them by recording time.

## Create review clips and mark favorites

Number five. Create review clips and mark favorites.

Tap Review and Trim Recordings to open the editor.

Tap Play to preview the selected original recording.

Pause near a moment that you want to keep.

Scroll to Trim a review clip. These controls set the section that you will save.

Move the Start slider to the beginning of the useful action.

Move the End slider to the end of that action. Check the selected duration.

Tap Save Clip. The app creates a separate edited movie and queues its upload.

To save another moment from the same recording, move Start to the next useful action.

Move End to finish the second selection.

Tap Save Clip again. One original recording can produce several independent review clips.

Scroll to Review Clips. Wait for Available before clearing an uploaded clip's local copy.

Tap the star beside a clip to mark that clip as a favorite.

A filled star means this clip is a favorite. Tap it again to remove the favorite mark.

Tap Done to return to the bout details.

The bout's star is an indicator. It fills when at least one clip in that bout is a favorite.

## Delete review clips

Number six. Delete review clips.

To delete a review clip, open Review and Trim Recordings again.

Scroll toward the review clip list.

Find the edited clip that you want to remove. Check its start and end times.

Tap Delete beside that clip.

Read the confirmation. Deleting removes the edited clip. It does not delete the original recording in Photos.

Tap Delete Clip to confirm. The app also removes the clip's cloud copy where applicable.

The other review clip remains. A cloud deletion that cannot finish immediately waits for recovery.

Tap Done to return to the bout.

We deleted the only favorite clip. The bout's star is now empty because no remaining clip is a favorite.

Close the bout details to return to the tournament.

## Clear local clip copies

Number seven. Clear local clip copies.

Open Fencer to manage the profile and local clip storage.

Clip storage shows local exports and downloaded copies. These values describe device storage, not working memory.

Tap Clear Local Clip Copies to free storage on this device.

This clears uploaded local exports and downloaded copies across bouts. It keeps clips in iCloud and protects pending uploads.

Tap Clear Local Copies to confirm. The app reports how many files it removed.

The local storage counts decrease. Saved cloud clips can download again when you play them with an available connection.

Your original recordings remain in Photos. You can now organize bouts, save useful clips, and review them together.
