# Editorial architecture video

An 8-minute 2-second presentation built from the monochrome architecture atlas. The earlier video remains in `../architecture-video/` and is unchanged.

Open [index.html](index.html) for the video page, or play [architecture-video.mp4](architecture-video.mp4).

The presentation includes an app-background opening, all seven atlas diagrams, nine chapters, 58 timed narration passages, and component outlines synchronized with the explanation. Complete diagrams remain visible throughout each chapter. Static scene changes preserve the editorial style; there are no camera moves or flashing effects.

## Outputs

- `architecture-video.mp4`: 1920 × 1080, 30 fps, H.264 video and AAC audio, chapter markers, captions burned into the picture.
- [narration.md](narration.md): plain reading script.
- [architecture-video.srt](architecture-video.srt): optional separate subtitles.
- [timeline.json](timeline.json): speech-aligned passage and chapter timings.
- `presentation.html`: complete static source slides and full narration.
- `narration.wav`: generated speech track.
- `poster.png`: introductory frame.

## Narration and visual sources

Narration uses the same stock ElevenLabs voice as the earlier video: `JBFqnCBsd6RMkjVDRZzb`, model `eleven_multilingual_v2`. Speech is generated by chapter using the [speech-with-timing endpoint](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps). Character alignment connects each passage to its exact text. Chapter audio is cached by content and voice settings to avoid repeat synthesis.

The practical STE-inspired target carries over from the earlier request: 1,171 words, 134 sentences, 8.7 words per sentence on average, maximum 17. This is a readability profile, not formal ASD-STE100 certification. Most code names remain visible in the diagrams instead of being read aloud.

Visual source: [editorial architecture atlas](../diagram-design/architecture.html), built with [Diagram Design](https://github.com/cathrynlavery/diagram-design). Its [style receipt](../diagram-design/style-guide.md) documents the Maria Vasilyeva reference palette and public font substitutes. The video reuses those inline SVGs, reframes them for 16:9, and adds a simple current-component outline. Original nodes, labels, and connectors are retained. The diagram eyebrow and legend are outside the video crop; solid arrows remain calls/dependencies and dashed arrows remain asynchronous cloud work.

## Reproduce

Requirements: Python with Playwright, Google Chrome, ffmpeg and ffprobe. Run from the repository root:

```sh
.venv/bin/python figures/tools/editorial-architecture-video/synthesize.py
.venv/bin/python figures/tools/editorial-architecture-video/render.py
python3 figures/tools/editorial-architecture-video/encode.py
python3 figures/tools/editorial-architecture-video/verify.py
.venv/bin/python figures/tools/editorial-architecture-video/verify_playback.py
```

The speech generator reads the ignored root `.env` or environment for `ELEVENLABS_API_KEY` / `ElevenLab_API`. It never includes credentials in generated artifacts or logs. Only the explanation text is sent for speech synthesis.

Large generated media and temporary frame/audio caches are ignored by Git. The storyboard, script, captions, timing, pipeline, and verification reports are committed.

## Validation

All 58 frames are checked for caption safe-area and node-label bounds. Representative frames are visually inspected. Final validation checks matching narration text, contiguous passage timing, language measurements, video size/codecs, nine chapter markers and full audio/video decode. Nine encoded chapter samples also match their source images at greater than 0.98 structural similarity, and browser playback passes. SHA-256 checks confirm the earlier video, HTML player and narration sources are unchanged.

No app executable code changed; simulator tests are not part of this media-only task.
